# Recipe Card Page

A responsive recipe card webpage featuring a delicious vegetable pasta recipe.

## Features
- Recipe image with caption
- Ingredients list
- Numbered preparation steps
- Clean and attractive card layout
- Responsive design for mobile and desktop

## Technologies Used
- HTML5
- CSS3

## How to Use
1. Open the recipe card webpage.
2. View the recipe image.
3. Check the ingredients required.
4. Follow the preparation steps to make the recipe.
